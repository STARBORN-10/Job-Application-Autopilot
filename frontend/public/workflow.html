Keys & services

Everything the system talks to, which setting holds its key, and where to set it. This page shows names only. Never put a real key in this page, in the frontend, or in git.

Two places, two jobs. Backend keys (job APIs, AI, Telegram, database) go into backend/.env locally and into the Render environment variables online. The Vercel project only needs VITE_API_URL. Anything stored in Vercel is baked into the public website, so no secret belongs there.

Job Application Autopilot

Upload your resume once. The system searches many job sources, scores every job against your resume, writes a cover letter, and tells you about the good ones. You decide where to apply. Nothing is applied for without your approval.

This page is a live map of that system. Each box is a step or a service, each line shows where data flows.
